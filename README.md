# 🐾 MichiMarket

**MichiMarket** es una aplicación web orientada a la venta y gestión de productos para mascotas. El proyecto contempla productos para **gatos, perros y cuyes**, con una experiencia pensada para organizar el catálogo y facilitar la administración de una tienda para mascotas.

Este repositorio forma parte de mi **portafolio de desarrollo** y refleja mi práctica construyendo aplicaciones web con tecnologías del ecosistema .NET.

## ✨ Características del proyecto

- Catálogo de productos para gatos, perros y cuyes.
- Organización de productos por categorías o tipos.
- Gestión de información de productos, como precio, stock e imágenes.
- Manejo de usuarios con roles de **administrador** y **cliente**.
- Información de perfil de usuario, incluida la foto de perfil.
- Estructura basada en el patrón **Modelo–Vista–Controlador (MVC)**.

> Las características disponibles pueden variar según el estado actual de desarrollo del proyecto.

## 🛠️ Tecnologías utilizadas

- **C#** — lenguaje principal de la aplicación.
- **ASP.NET MVC** — framework y patrón de arquitectura para la aplicación web.
- **HTML** — estructura de las páginas.
- **CSS** — estilos y presentación visual.
- **JavaScript** — interactividad del lado del cliente.
- **SQL Server** — gestión de datos, si corresponde a la configuración incluida en el proyecto.
- **Visual Studio 2026** — entorno de desarrollo utilizado.

## 🧱 Arquitectura

El proyecto sigue el enfoque **MVC (Model–View–Controller)**, que separa responsabilidades para facilitar la organización y el mantenimiento del código:

- **Models:** representan los datos y las entidades de la aplicación.
- **Views:** muestran la interfaz que utiliza el usuario.
- **Controllers:** reciben las solicitudes y coordinan el flujo de la aplicación.

## 🎯 Objetivo

Desarrollar una aplicación web para una tienda de productos para mascotas y reforzar conocimientos de desarrollo web, organización de aplicaciones MVC, gestión de usuarios y administración de productos.

## 🚀 Cómo ejecutar el proyecto

1. Clona este repositorio:
   ```bash
   git clone https://github.com/Angelostin43/MichiMarket-2.0.git
   ```
2. Abre la solución del proyecto en **Visual Studio 2026**.
3. Restaura los paquetes NuGet si Visual Studio lo solicita.
4. Revisa la configuración de conexión a la base de datos y ajústala a tu entorno local.
5. Configura o inicializa la base de datos según los archivos incluidos en el repositorio.
6. Ejecuta la aplicación desde Visual Studio.

> **Nota:** los pasos exactos pueden depender de la configuración de la base de datos y de los archivos incluidos en la versión actual del repositorio.
